# Measured 3D objects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every tracked object in the visualizer a measured 3D presence: its compiled track, an
estimated metric size, and a fused depth-map shape, with nothing invented.

**Architecture:** The headset records depth samples inside each tracked outline (the only part that
must run live, since the depth map exists only in an XR frame). The compiler turns boxes, depths and
intrinsics into a metric extent per object and fuses the samples, relative to the object's tracked
position, into a point set and a yaw-aligned box (`shapes.json`). The visualizer draws the compiled
tracks instead of raw estimates when a compile exists, with the extent box and the shape attached.

**Tech Stack:** zod contracts in `packages/protocol`; TypeScript headset (vitest); Python pipeline
(numpy, pytest, uv); Next.js/R3F visualizer (Bun, bun:test).

**Spec:** the chat decision of 2026-10-24 ("start on the measured 3D path: draw tracks.json in the
visualizer, compile metric extents per object, and record depth samples inside each tracked outline
for a fused shape"), plus `visualizer/GOALS.md` rule 5 (never invent measurements).

## Global Constraints

- Every spatial value in raw and compiled files is in the workspace frame W, meters; times in episode ms.
- Compiled files never contain NaN; `null` marks no value. Estimated and measured values are labelled as such in the viewer.
- Raw capture files are append-only; new raw fields are optional and announced in `meta.features`.
- No bullets, arrows, outlined chips, gradients or status text with no decision in UI copy (user's UI rules).
- The visualizer imports shared code only through `@clio/protocol` and the allowed `@clio-viewer/*` modules; Bun inside `visualizer/`, pnpm elsewhere; never `--turbopack`.
- Pipeline version bumps to `0.6.0` (compile output changes).

## Review Focus

1. An episode recorded before this change (no `surface`, no `meta.camera`): compile still succeeds, `extent` is null, the shapes stage is skipped, the viewer draws tracks without boxes. Pinned in Task 3 (`test_shapes_stage_is_skipped_without_samples`) and Task 4 (extent null draws nothing).
2. An object held while sampled: its samples would smear the shape; frames inside held spans are dropped. Pinned in Task 3.
3. Depth samples that hit the background behind a small object: dropped by the 0.3 m reach around the measured center. Pinned in Task 2.

5. The viewer at a time before the compiled grid starts or after it ends: no position, nothing drawn, no stale pose. Pinned in Task 4.

### Task 3: Pipeline: metric extents and fused shapes

**Files:**
- Create: `pipeline/src/clio_pipeline/extents.py`, `pipeline/src/clio_pipeline/shapes.py`
- Modify: `pipeline/src/clio_pipeline/compile.py` (extent in `_object_doc`, `shapes` stage writing `shapes.json`), `pipeline/src/clio_pipeline/__init__.py` (0.6.0)
- Modify: `pipeline/tests/conftest.py` (`observation(..., surface=None)`, camera meta helper)
- Test: `pipeline/tests/test_extents.py`, `pipeline/tests/test_shapes.py`, `pipeline/tests/test_compile.py`

**Interfaces:**
- Consumes Task 1's contract and `ObjectSeries` (objects.py), `Episode.head`/`Episode.t`, `meta.camera`.
- Camera convention (mirror `apps/headset/src/domain/world/camera-model.ts` pixelRay): camera pose = head pose at observedT (interpolate position, nlerp quaternion between the recorded frames) composed with `headFromCamera`; a pixel (u, v) normalized maps to camera-frame direction `[(u*W - cx)/fx, -(v*H - cy)/fy, -1]`; the camera looks along -z.
- `object_extents(episode, series) -> dict[str, dict | None]`: per object, over observations with status `measured`, a `box`, and a valid tracked compiled position at the nearest grid frame to observedT: depth z = dot(position - camera_p, camera_forward); width = box_w * W / fx * z; height = box_h * H / fy * z; W, H from `obs.frame` else the intrinsics. Median of at least 3 samples as `{"width", "height", "samples"}` rounded to mm, else None. None for every object without `meta.camera`.
- `object_shapes(episode, series, *, voxel_m=0.01, min_hits=2, max_points=2000) -> dict[str, dict]`: per object with `surface` samples on `measured` observations: offsets = sample - compiled position at the nearest grid frame; skip frames where that position is not valid or the object is held; voxelize offsets at `voxel_m`, keep voxels with at least `min_hits` hits when more than 50 voxels exist, each voxel its mean; cap to `max_points` by uniform stride; box from the yaw of the principal horizontal axis (PCA on x, z), size from the 2nd to 98th percentile along [principal, up, perpendicular], center at the middle of those ranges, rotation `[0, sin(yaw/2), 0, cos(yaw/2)]`; `samples` counts raw points, `frames` contributing observations, `firstT`/`lastT` their observedT.
- `shapes_doc(episode, shapes, *, voxel_m, min_hits, reach_m=0.3) -> dict` (ShapesDoc). The `shapes` stage is `skipped` with detail `no depth samples` when no observation carries `surface`.

- [ ] Failing tests: an object 1.0 m in front of a camera with fx = fy = 800, W = 1280, H = 960 and a box 0.1 wide and 0.05 high measures 0.16 x 0.06 m; fewer than 3 samples or no camera gives None; two static frames of samples fuse into one point set with offsets relative to the position, a held frame is skipped, a frame whose compiled position is null is skipped, the box yaw follows an elongated point set; compile writes `shapes.json` of kind `shapes` and reports `extent`, and skips the stage without samples.
- [ ] Implement; `cd pipeline && uv run --frozen pytest -q` PASS (regenerated protocol schemas validate the output); `uv run --frozen ruff check src tests` and `ruff format --check` clean.
