# Demo photos

Test images for `/primary.html?image=/demo/<file>.jpg`, which replaces the passthrough camera
with a still photo so the whole loop runs in a desktop browser. Both are unmodified Wikimedia
Commons thumbnails (1280 px wide), copied from the Jev fun workbench (`data/images/micrometer.jpg`
and `data/images/tools.jpg`; sources in its `data/benchmark.json`).
